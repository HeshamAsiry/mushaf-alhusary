# مصحف الحصري

مشروع لإعادة بناء تسجيل مصحف الشيخ محمود خليل الحصري من المقاطع المصدرية، مع الحفاظ على الصوت الأصلي قدر الإمكان.

## البنية

- **GitHub**: الكود
- **Neon**: PostgreSQL للبيانات الوصفية والتوقيتات وحالة المراجعة
- **Cloudflare R2**: تخزين ملفات الصوت
- **Railway**: تشغيل التطبيق والـworker في مرحلة لاحقة

## تخزين الصوت في R2

داخل الـbucket نستخدم المفاتيح التالية:

- `raw/` — المقاطع الأصلية، ولا يتم تعديلها.
- `processed/` — الملفات الناتجة قبل الاعتماد.
- `public/` — الملفات المعتمدة للنشر.

هذه ليست Buckets منفصلة؛ هي prefixes داخل Bucket واحد.

## الصوت

لا نستخدم:
- Reverb / Echo
- Noise reduction
- AI enhancement
- EQ مؤثر
- Compression مؤثر
- Pitch/time changes
- Crossfade غير موجود في المصدر

المسموح فقط: القص والتجميع الدقيق، وresampling التقني عند الحاجة، وloudness normalization عند اعتماده مع منع clipping.

## الإعداد المحلي

1. انسخ `.env.example` إلى `.env.local`.
2. املأ القيم الموضحة بالتعليقات.
3. لا ترفع `.env.local` إلى GitHub.

## الحالة الحالية

المرحلة الحالية هي تجهيز البنية وربط Neon وCloudflare R2 قبل بناء معالجة الصوت ونظام المراجعة.
